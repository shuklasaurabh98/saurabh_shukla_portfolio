# Portfolio Website

A beautiful, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features

- **Responsive Design**: Works perfectly on all devices (desktop, tablet, mobile)
- **Smooth Scrolling**: Smooth navigation between sections
- **Animations**: Fade-in animations on scroll
- **Modern UI**: Clean and professional design
- **Interactive Elements**: Hover effects and active navigation highlighting
- **Sections**: Home, About, Projects, Skills, and Contact

## Files

- `index.html` - Main HTML file with structure
- `styles.css` - All styling and responsive design
- `script.js` - JavaScript for interactivity and animations
- `assets/Saurabh_Shukla_CV.pdf` - CV file used by the Download CV buttons
- `README.md` - This file

## How to Use

1. Open `index.html` in your web browser
2. Customize the content with your information:
   - Update your name in the hero section
   - Add your bio in the about section
   - Update project details
   - Replace the placeholder email and social links
   - Update your avatar image URL
   - Add your CV as `assets/Saurabh_Shukla_CV.pdf` so recruiters can download it directly

## Customization

### Update Personal Information
- Edit the text in each section in `index.html`
- Replace email and social links in the contact section

### Modify Colors
- Edit the CSS variables in `styles.css`:
  ```css
  --primary-color: #3b82f6;
  --secondary-color: #a855f7;
  ```

### Add More Projects
- Add more `project-card` divs in the projects section
